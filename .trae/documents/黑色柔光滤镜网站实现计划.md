# 黑色柔光滤镜渲染网站 — 实现计划

## Context（为什么做）
用户需要一个部署在 GitHub Pages 的单页网站，具备三项能力：
1. **电影暗调柔光滤镜**：黑色柔光把图片/视频渲成暗调电影质感（压暗、压低高光、暗角、轻度降饱和、电影感曲线）。
2. **点击取色**：在图片或视频上点击某个物品，提取该区域代表色。
3. **选择问答题调色**：弹出选择题问“这个颜色是什么颜色”，分析其混入的杂色，自动生成调色参数在滤镜中去除杂色。

技术栈：React + Vite，构建后自动部署到 GitHub Pages。环境：node v24 / npm 11 / git 已具备；`gh` CLI 未安装，GitHub 仓库由用户手动创建。

## 核心设计决策
- **滤镜渲染路线：CSS filter 链 + 覆盖层（方案1，推荐）**
  - `<img>`/`<video>` 直接加 `filter: contrast(1.08) saturate(0.82) brightness(0.92) sepia(0.05)`，浏览器 GPU 合成、对视频零逐帧 JS 开销，天然 60fps。
  - 舞台叠层：径向渐变暗角（`mix-blend-mode:multiply`）+ 黑色柔光上下渐变层（`mix-blend-mode:soft-light`）压暗并压低高光。
  - **去杂色**也用 CSS：`hue-rotate(dh) saturate(sf) brightness(bf) contrast(cf)` 拼进 filter 链。CSS 是线性变换无法做局部色相收敛，但修正量小、画面为暗调，视觉可接受（WebGL 片段着色器作备用，本轮不实现）。
  - 拼接顺序：`finalFilter = 去杂色段 + 空格 + 基础电影段`。
- **取色必须读未滤镜帧**：CSS 滤镜只是渲染效果、不影响源纹理。离线 canvas 里画原始帧取色：
  - 图片：`drawImage(img)`；视频：先 `video.pause()`，`drawImage(video, ...)` 取当前帧再 `play()`。
  - onLoad/onClick 因播放进度不同，需取“点击瞬间”的当前帧。
  - **object-fit:contain 坐标换算**：`scale=min(SW/mw,SH/mh)`，`drawW=mw*scale,drawH=mh*scale`，`ox=(SW-drawW)/2,oy=(SH-drawH)/2`，`src=(clientXY - o)/( 1/scale)`；对点击点 11×11 邻域取 RGB 平均。
- **颜色科学（纯函数，可单测）**
  - `rgbToHsv` → 感知主色分桶（10 桶：红/橙/黄/绿/青/蓝/紫/粉/灰/黑或白）。`s<0.10` 归灰/白/黑；否则按色相区间命名。
  - 每桶定义“理想纯主色”原型 `(Hc,Sref=0.85,Vref=0.8)`；杂质 = 与原型偏差：
    - `dH=shortestHueDist(h,Hc)`（`((a-b)+180)%360-180`）；`|dH|>=10` ⇒ “混入了 dH° 偏{方向}的{相邻色}”
    - `satGap=Sref-h.s` >0.15 ⇒ “饱和度不足…发灰”
    - 明度偏差 ⇒ “偏白/偏黑”
  - 去杂色参数：`hueRotate=dH`、`satFactor=clamp(Sref/max(s,.01),.7,3)`、`brightness=clamp(1+0.6*(Vref-v),.6,1.35)`、`contrast=1+0.3*max(0,0.8-s)`。

## App 状态（集中在 App.jsx）
- `source:{url,isVideo,width,height}`
- `filter:{contrast,sat,bright,sepia,vignette,softLight}` 基础电影 look
- `cleanup:{hueRotate,satFactor,brightness,contrast}|null` 去杂色
- `sample:{x,y}|null` 取样框位置
- `quiz:{open,answer}|null`、`report:string[]|null` 杂色分析

## 交互数据流
点击 → MediaStage 用未滤镜帧采样得 RGB/HSV → 显示取样框 → 弹 ColorQuiz → 选桶 → detectImpurities 出报告 + generateCleanupParams 生成 cleanup → 回填 App.cleanup → filter 链重算实时生效。

## 部署（GitHub Actions，`gh` 未装故用户手动建仓一次）
`vite.config.js` 用 `base:'./'`（相对路径，子路径可用）。
`deploy.yml`：
- `on: push:{branches:[main]} + workflow_dispatch`
- `permissions:{contents:read, pages:write, id-token:write}`
- jobs: `actions/checkout@v4` → `actions/setup-node@v4`(node-version:24, cache:npm) → `npm ci` → `npm run build` → `actions/configure-pages@v5` → `actions/upload-pages-artifact@v3`(path:./dist) → `actions/deploy-pages@v4`

用户手动步骤：GitHub 建空仓库 → `git init`、`git branch -M main`、`git remote add origin <repo>`、`git push -u origin main` → 仓库 Settings→Pages→Source 选 **“GitHub Actions”**。

## 实施顺序
1. 脚手架 + 部署 workflow（先可空构建）。
2. `src/lib/color.js` + `media.js` 纯函数层。
3. Uploader + MediaStage 基本显示与滤镜。
4. 点击取色 + 取样框（含 object-fit 换算、视频帧同步）。
5. ColorQuiz 选择题 + 杂色分析报告。
6. FilterControls + CompareSlider 收尾。

## 验证方式
- `npm run dev` 本地：上传 jpg/png/video mp4，确认实时暗调柔光滤镜、暗角、柔光层生效。
- 点击画面物品 → 取样框出现 → 弹选择题 → 选择后报告显示杂色文案，画面颜色被去杂色微调。
- 对比滑块拖动前后对比正常。
- `npm run build` 通过且产物为相对路径；推 main 后 Actions 自动部署；`npx serve dist` 预检产物。
